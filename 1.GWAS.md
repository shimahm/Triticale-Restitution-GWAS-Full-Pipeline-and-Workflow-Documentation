# Pipeline Architecture

## 📁 Input Data Sources

### Genotypic Data: `Tabela_S1.xlsx`
- **Marker IDs:** `Nr` column (unique SNP identifiers)
- **Genomic Positions:** `Chromosom` (1A–7A, 1B–7B, 1R–7R) and `Kosambi` (genetic map positions in cM)
- **Genotype Calls:** Sample columns with `a/b` alleles and `-` for missing data

### Phenotypic Data: `20250304_pheno_2n_gametes_ABDR.csv`
- **Sample IDs:** `Plant` column (individual accessions)
- **Trait Measurements:** `rest_1` to `rest_5` (restitution traits)

---

## 1. Data Processing & Quality Control

- **Script:** `preparing_for_GAPIT.py`

#### Processing Steps
- **Data Cleaning:** Filters markers (>20% missingness) and samples (>20% missing genotypes)
- **Quality Control:** Removes monomorphic SNPs, retains only polymorphic markers
- **Genotype Encoding:** Converts `a` → 0, `b` → 2 for additive genetic model
- **ID Harmonization:** Matches individuals between genotype and phenotype files using Taxa identifiers

#### Output Files
- `GAPIT_genotype.csv` — Genotype matrix (Individuals × SNPs, encoded as 0/2)
- `GAPIT_phenotype.csv` — Phenotype matrix (Individuals × 5 restitution traits)
- `GAPIT_snp_metadata.csv` — SNP information (Marker, Chromosom, Kosambi positions)

---

## 2. GWAS Statistical Analysis

- **Script:** `GWAS_kosmbi_full_pipeline_all_models.R`

#### Analysis Framework
- **Chromosome Organization:** Orders triticale genome as 1A–7A, 1B–7B, 1R–7R
- **Data Integration:** Intersects SNPs across genotype and metadata files
- **Missing Data Imputation:** Uses major allele for genotype imputation
- **Multiple Model Approach:** Runs 11 GWAS models for comprehensive analysis

#### Statistical Models Implemented
- **Single-locus:** GLM, MLM, CMLM, ECMLM
- **Multi-locus:** SUPER, MLMM, FarmCPU, BLINK
- **Genomic Prediction:** gBLUP, cBLUP, sBLUP

#### Output Structure
```
GAPIT_results/
├── trait_1/
│   ├── model_1/
│   │   ├── Manhattan.pdf
│   │   ├── Significant_SNPs_p001.csv

```

---

## 3. Data Integration & Key Relationships

### Cross-File Linkages

| File                   | Primary Key | Links To                       |
|------------------------|-------------|--------------------------------|
| GAPIT_genotype.csv     | Taxa        | Phenotype file via sample IDs  |
| GAPIT_phenotype.csv    | Taxa        | Genotype file via sample IDs   |
| GAPIT_snp_metadata.csv | Marker      | Genotype file via SNP IDs      |

### Critical Transformations
- **Genetic Map:** Kosambi cM → pseudo-bp coordinates for visualization
- **Chromosome Coding:** Text labels (1A, 2B) → numeric codes for statistical analysis
- **Statistical Output:** Raw P-values → `-log₁₀(P)` for Manhattan plots

---

## 4. Significant SNP Processing & Annotation

### Workflow Components
- **Significant Marker Extraction:** Filters GWAS results at p < 0.01 and p < 0.005 thresholds
- **Sequence Annotation:** Links significant SNPs to their genomic sequences
- **BLAST Analysis:** Maps markers to reference genomes for functional interpretation
- **Linkage Disequilibrium:** Calculates LD patterns around significant loci
